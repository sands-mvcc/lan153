Mission Briefing: Address Resolution Protocol (ARP) Poisoning

tap to collapse ▾

Security+ 2.4 / 2.5MITRE ATT&CK T1557.002CIA: Confidentiality & Integrity

What is ARP? The Address Resolution Protocol maps a known IPv4 address to the physical (MAC) address a switch needs to deliver a frame on the local segment. ARP has no built-in authentication — any host on the LAN can broadcast an ARP reply, and other hosts will trust it and update their local ARP cache without verification.

What is ARP poisoning (ARP spoofing)? An attacker sends forged, unsolicited ARP replies telling the victim "I am the gateway" and telling the gateway "I am the victim." Because ARP is stateless and unauthenticated, both machines silently overwrite their ARP cache with the attacker's MAC address. Traffic that should flow directly between the victim and the gateway is now routed through the attacker's machine first — a classic on-path (man-in-the-middle) attack that enables traffic interception, session hijacking, or denial of service.

  • Learning objective: Use native Windows commands to inspect and poison an ARP table, then verify the redirection.
  • Learning objective: Use native Linux commands to enable IP forwarding, poison an ARP table bidirectionally, and capture the diverted traffic.
  • Learning objective: Identify controls (Dynamic ARP Inspection, static ARP entries, port security) that mitigate this attack class.

Scenario Topology

Three hosts share a single unmanaged Layer 2 switch in a small office segment (192.168.1.0/24). You control the Attacker Workstation, a dual-boot lab machine you can operate from either its Windows or Linux install.

Rules of Engagement

This is an isolated lab network you are authorized to test. In the real world, ARP poisoning outside a network you own or have written authorization to test is illegal under most computer-fraud statutes.

Note on realism: native Windows arp only manages the local host's cache and cannot forge replies toward a remote host. This lab includes a bundled instructional utility, labspoof.exe, so you can practice the Windows-side workflow. In the field, Windows-based attackers typically use a packet-capture-driven tool (Cain & Abel, Ettercap for Windows) or pivot through WSL/Kali — arpspoof on Linux remains the more common real-world tool.
