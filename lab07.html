Mission Briefing

Welcome to the Security Operations Center

You have been assigned as a Tier 1 SOC Analyst for a mid-size enterprise network with both wired and wireless segments — office workstations, a wireless faculty/guest VLAN, internal servers, and a public-facing DMZ web server. Network-based (NIDS) and host-based (HIDS) sensors are streaming alerts to your console.

Your job: read each raw alert exactly as an analyst would in a SIEM, decide what type of attack it represents, and justify it using the indicators of compromise (IOCs) in the log — source/destination addresses and ports, protocol flags, payload content, timing, and volume.

What you'll practice

  • Distinguishing signature-based alerts (matches a known attack pattern) from anomaly-based alerts (deviates from a normal baseline).
  • Reading NIDS output (Suricata/Snort-style), HIDS logs (auth/syslog-style), and Layer 2 anomaly reports (ARP).
  • Identifying six common attack categories from their alert signatures and behavioral indicators.
  • Mapping each finding to real-world frameworks used in industry: MITRE ATT&CK and the CompTIA Security+ exam objectives.

The six attack categories in this exercise

  • Reconnaissance / Port Scanning — an attacker probing which services are open.
  • Brute-Force / Credential Attack — repeated login attempts to guess credentials.
  • Denial-of-Service (DoS/DDoS) Flood — overwhelming a system to deny legitimate use.
  • SQL Injection — malicious database syntax inserted into an application input.
  • Cross-Site Scripting (XSS) — malicious script injected into a web page/response.
  • ARP Spoofing / On-Path (MITM) Attack — forged Layer 2 addressing to intercept traffic.

There are 6 alerts total. Each is worth up to 10 points (60 points possible). Using a hint costs 2 points; an incorrect attempt costs 3 points before you can try again. After two incorrect attempts on a single alert, the correct answer is revealed so you can move on and keep learning.
