Course Information

Course Description

Prerequisite: LAN-122 or consent of instructor

Credit Hours: 3

Contact Hours: 4 (2 Lecture/Demonstration + 2 Lab/Studio)

This course introduces the basic principles of network security. The student will be introduced to computer network vulnerabilities and threats and how to safeguard computer networks from those vulnerabilities and threats. This course will expose the student to network security planning, network security technology, network security organization and the legal and ethical issues associated with network security. This course is designed to prepare the successful student for the CompTIA Security+ certification.

Major Course Concepts

A. Network Security Basics

  • Security Definitions, Network security principles and objectives
  • Network security architecture, model, and layers
  • Network threats, confidentiality, integrity and availability
  • Accountability, auditability, and non-repudiation
  • Case study of the network security policy of the student's parent organization

B. Network Security Planning

  • Network risk management and network security policy
  • Continuity of operations and security maintenance
  • Policy, procedures, standards, and guidelines
  • Case study of a risk assessment of the student's parent organization

C. Network Security Technology

  • Cryptography, virtual private networks, firewalls and intrusion detection system
  • Scanning and analysis tools and access controls

D. Network Security Organization

  • The organization and security
  • Personnel and security
  • The Computer Incident Response Team (CIRT)
  • The security function to include organization, location, responsibility, and resources
  • Case study to create a Computer Incident Response Team

E. Legal, Privacy, and Ethical Issues

  • US Laws and Network Security
  • Privacy and network security
  • Ethics and Network Security
  • Class exercise in developing a code of Network Security ethics

Expected Learning Outcomes

Upon successful completion of this course, students will be able to:

  1. Understand computer, network and information security
  2. Explain why network security is important
  3. Explain network security prevention, detection and response
  4. Define and explain the concept of network confidentiality, integrity and availability
  5. Define and explain the concept of non-repudiation
  6. Understanding management's role in the development, implementation and maintenance of network security
  7. Understand the value of education, training and awareness programs to the organization
  8. Understand security architecture, its principles, components and employment
  9. Define risk management and its role in security policy and security architecture
  10. Understand the relationship between risk, threats, vulnerabilities and countermeasures
  11. Identify and describe risk mitigation strategies
  12. Define and describe Disaster Recovery Plans
  13. Define and describe an Incident Response Plan
  14. Define and describe a Business Continuity Plan
  15. Describe the various functions related to database security
  16. Describe and understand a feasibility study
  17. Understand the need for constantly evaluating the status of security management
  18. Understand the difference between policies, procedures, standards and guidelines
  19. Understand the process of encryption and define the key cryptography terms
  20. Understand the difference between asymmetric and symmetric encryption
  21. Discuss scanning and analysis tools
  22. Describe the various types of firewalls
  23. Describe the various types of Intrusion Detection Systems
  24. Describe the operation of Virtual Private Networks
  25. Understand the importance of authentication and the characteristics of a good password
  26. Describe the various approaches to biometrics access control
  27. Understand the position of the network security element within the organization
  28. Understand the skills required to staff the network security element
  29. Describe the functional elements associated with network security
  30. Understand the relationship between an organization's employment practices and policies and the network security function
  31. Understand the position of the CIRT element within the security function
  32. Explain the various credentials that can be acquired by the security professional and their value
  33. Identify and explain the major laws relating to network security
  34. Understand the issue of privacy and its impact upon the network security function
  35. Understand the issue of ethics and its relationship to the security function
  36. Explain the difference between ethics and laws, and explain the purpose of a code of ethics
  37. Understand the potential for organizational liability with regard to network security
  38. Understand and describe the tradeoffs security, privacy and operations
